# House-Prices-Data-Preprocessing

This project focuses on data preprocessing for the House Prices dataset using Python.

## Steps Performed
- Data loading using Pandas
- Missing value handling
- Outlier removal
- Log transformation
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Encoding categorical variables

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
